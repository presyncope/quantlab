# 국내장 Phase 1 장전 리서치 템플릿 구현 보고서

> 목적: 국내장(KOSPI/KOSDAQ) 전용으로 **장전 리서치 → 후보 종목 선정 → 장중 시그널 보조 → 수동 판단 → 장후 리뷰** 루프를 만들기 위한 Phase 1 구현 문서입니다.  
> 범위: 자동매매/복잡한 전략 검증이 아니라, 사람이 더 좋은 판단을 내리도록 돕는 **장전 리서치 템플릿 시스템**입니다.

---

## 0. 한 줄 결론

Phase 1의 목표는 “매수 신호를 자동 생성하는 시스템”이 아니라, **매일 아침 같은 기준으로 시장·섹터·종목을 정리하고, 오늘 볼 종목과 보지 않을 종목을 구분하며, 장중에는 VWAP/거래량/가격구조 시그널을 진입 검토용 보조 데이터로 사용하는 시스템**을 만드는 것입니다.

처음부터 복잡한 알고리즘, 백테스트, 자동주문, AI 매수 추천을 만들기보다 아래 순서로 가는 것이 효율적입니다.

```text
장전 시장 브리핑
  ↓
섹터/테마 맵
  ↓
후보 종목 리스트
  ↓
종목별 판단 카드
  ↓
A/B/C/제외 등급 확정
  ↓
장중 VWAP·거래량·전고점 알림
  ↓
사용자 수동 진입/보류/무시
  ↓
장후 판단/실행/결과 리뷰
```

---

## 1. Phase 1의 정확한 정의

### 1.1 Phase 1에서 만들 것

Phase 1은 **국내장 장전 리서치 템플릿 + 판단 기록 시스템**입니다.

핵심 기능은 다음과 같습니다.

| 구분 | 목적 |
|---|---|
| 시장 브리핑 | 오늘 공격적으로 볼지, 방어적으로 볼지 판단 |
| 섹터/테마 맵 | 오늘 돈이 몰릴 가능성이 높은 영역 찾기 |
| 후보 종목 리스트 | 하루에 볼 종목을 5~15개 수준으로 압축 |
| 종목별 판단 카드 | 왜 이 종목을 보는지, 어떤 조건에서 볼지 정리 |
| A/B/C/제외 등급 | 장중 집중할 종목과 버릴 종목 분리 |
| 장중 시그널 연결 | VWAP, 거래량, 전일 고가/저가 등 단순 시그널 알림 |
| 판단 로그 | 장전 판단과 실제 결과를 비교하기 위한 기록 |
| 실행 로그 | 내가 시그널을 따랐는지, 무시했는지, 늦게 들어갔는지 기록 |
| 장후 리뷰 | 판단 문제와 실행 문제를 분리해서 개선 |

### 1.2 Phase 1에서 만들지 않을 것

처음에는 아래 기능을 뒤로 미루는 것이 좋습니다.

| 제외 항목 | 제외 이유 |
|---|---|
| 완전 자동매매 | 현재 목표는 사람이 최종 판단하는 시스템이기 때문 |
| 복잡한 백테스트 | 정적 전략이 아직 없고, 우선 판단 데이터를 쌓아야 함 |
| 다수 지표 조합 최적화 | 과최적화와 혼란 가능성이 큼 |
| AI 매수/매도 추천 | AI는 요약·분류·반대논리 제시까지만 담당해야 함 |
| 수십 개 이상의 실시간 알림 | 알림 피로와 충동매매를 유발할 수 있음 |
| 전 종목 무제한 스캐닝 | 초기에는 장전 후보 종목 중심으로 제한해야 함 |

## 2. 전체 운영 구조

### 2.1 Top-down 구조

초기 시스템은 아래 순서를 따라야 합니다.

```text
시장 상태
→ 섹터/테마
→ 종목 후보
→ 가격 위치
→ 장중 시그널
→ 수동 실행
→ 장후 리뷰
```

반대로 아래 순서는 피해야 합니다.

```text
장중 시그널 발견
→ 왜 올랐는지 검색
→ 뉴스가 좋아 보임
→ 즉흥 진입
```

두 번째 방식은 장중에 시장에 끌려다니게 만듭니다. Phase 1의 핵심은 **장전 후보를 먼저 정하고, 그 후보에서만 시그널을 받는 구조**입니다.

### 2.2 시스템의 역할 분담

| 구성 요소 | 역할 |
|---|---|
| 장전 리서치 템플릿 | 오늘 볼 종목과 근거를 정리 |
| 점수/등급 체계 | 관찰 우선순위를 결정 |
| ChartView | 장중 가격 반응과 시그널 확인 |
| 알림 시스템 | 진입 검토 구간을 알려줌 |
| 사용자 | 최종 진입/보류/무시 판단 |
| 로그 DB | 판단과 실행의 차이를 저장 |
| 장후 리뷰 | 내 판단력과 실행력을 개선 |

## 3. Phase 1 템플릿 구성

Phase 1 템플릿은 크게 6개로 구성하는 것을 추천합니다.

1. 오늘의 시장 브리핑
2. 섹터·테마 맵
3. 후보 종목 리스트
4. 종목별 판단 카드
5. 오늘의 작전표
6. 장후 리뷰 연결 필드

---

## 4. 템플릿 A: 오늘의 시장 브리핑

### 4.1 목적

시장 브리핑은 오늘 장에서 **공격적으로 볼지, 방어적으로 볼지, 특정 섹터만 선별할지**를 결정하는 화면입니다.

국내장은 전일 미국장, 환율, 금리, 국내 전일 흐름, 외국인/기관 수급, 주요 공시/뉴스의 영향을 많이 받기 때문에 장전 시장 상태를 먼저 정리해야 합니다.

### 4.2 필수 필드

| 필드 | 설명 | 결과 예시 |
|---|---|---|
| 날짜 | 거래일 | 2026-05-28 |
| 시장 모드 | risk-on / neutral / risk-off | neutral |
| 전일 KOSPI | 전일 지수 등락 및 거래대금 | +0.8%, 거래대금 증가 |
| 전일 KOSDAQ | 성장주/테마주 분위기 | -0.3%, 바이오 약세 |
| 미국장 영향 | 나스닥, S&P500, 필라델피아 반도체 등 | 나스닥 강세, 반도체 우호 |
| 환율 | 달러/원 방향 | 상승 부담 |
| 금리 | 미국 금리, 국내 금리 방향 | 성장주 부담 |
| 주요 이벤트 | 국내외 지표, FOMC, 실적, 정책 발표 | 장후 미국 CPI |
| 오늘 우선 섹터 | 장전 기준 관심 섹터 | 반도체, 전력기기 |
| 오늘 회피 섹터 | 약하거나 과열된 섹터 | 게임, 건설 |
| 오늘 운영 원칙 | 매매 강도와 금지 조건 | 시초 추격 금지, 눌림 확인 |

NOTE: 미국 단기채, 장기채 금리도 중요할듯?

### 4.3 구현 방법

| 구현 요소 | 구체적 방안 |
|---|---|
| 데이터 수집 | 전일 국내 지수, 업종/테마, 거래대금, 외국인/기관 수급을 장후 또는 장전 배치로 수집 |
| 해외 영향 | 나스닥, S&P500, 반도체 지수, 원/달러, 미국 금리 등은 장전 요약값으로 저장 |
| 자동 요약 | 수집된 값으로 “시장 모드 초안”을 자동 생성 |
| 사람 수정 | 최종 risk-on/neutral/risk-off 판단은 사람이 수정 가능하게 함 |
| 저장 | 날짜별 `daily_market_brief` 형태로 저장 |

### 4.4 브리핑 문장 템플릿

```text
오늘 시장은 [risk-on/neutral/risk-off]에 가깝다.
전일 국내장은 [KOSPI/KOSDAQ 흐름]이었고, 야간 미국장은 [미국장 영향]을 보였다.
장전 기준 우선 관찰 섹터는 [섹터1, 섹터2]이며, 회피 섹터는 [섹터3]이다.
오늘은 [운영 원칙]을 우선 적용한다.
```

## 5. 템플릿 B: 섹터·테마 맵

### 5.1 목적

단기매매에서는 개별 종목보다 **섹터/테마의 동반 강도**가 중요할 때가 많습니다. 섹터·테마 맵은 오늘 어떤 영역에 돈이 몰릴 가능성이 있는지 판단하기 위한 화면입니다.

### 5.2 필수 필드

| 필드 | 설명 | 예시 |
|---|---|---|
| 섹터명 | 반도체, 2차전지, 바이오 등 | 반도체 |
| 전일 등락 | 섹터 대표 종목 또는 테마 평균 등락 | +2.3% |
| 거래대금 변화 | 전일 대비 거래대금 증가 여부 | +45% |
| 대장주 | 해당 섹터의 가장 강한 종목 | SK하이닉스 |
| 후발주 | 대장주 따라 움직일 후보 | 관련 소형주 |
| 뉴스/공시 연결 | 당일 이슈 | AI 서버 수요 기대 |
| 미국장 연동 | 미국 관련 섹터 강세 여부 | SOX 강세 |
| 과열 여부 | 연속 급등, 갭 과열 등 | 3일 연속 강세 |
| 오늘 판단 | 관심 / 중립 / 회피 | 관심 |

### 5.3 구현 방법

| 구현 요소 | 구체적 방안 |
|---|---|
| 섹터 분류 | 초기에는 완벽한 GICS 분류보다 직접 관리하는 관심 섹터 태그로 시작 |
| 대장주 지정 | 섹터별 대표 종목을 수동 테이블로 관리 |
| 섹터 강도 계산 | 섹터 내 주요 종목의 전일 등락률, 거래대금 증가율, 상대 강도를 단순 평균/가중평균 |
| 뉴스 연결 | 뉴스·공시 키워드를 섹터 태그와 매핑 |
| 화면 표시 | 섹터를 관심/중립/회피로 컬럼 구분 또는 히트맵으로 표시 |

### 5.4 섹터 태그 예시

| 태그 | 대표 관찰 대상 |
|---|---|
| 반도체 | 대형 반도체, 장비, 소재, HBM, 패키징 |
| 2차전지 | 셀, 소재, 장비, 리튬, 폐배터리 |
| 바이오 | 제약, 임상, CDMO, 진단 |
| AI/소프트웨어 | AI, 클라우드, 데이터센터, 보안 |
| 전력기기 | 변압기, 전선, 전력 인프라 |
| 방산 | 항공, 무기체계, 부품 |
| 조선/해운 | 조선사, 기자재, 해운 |
| 원전/에너지 | 원전, 재생에너지, 유가 민감주 |
| 금융 | 은행, 증권, 보험 |
| 소비재 | 화장품, 음식료, 유통 |

## 6. 템플릿 C: 후보 종목 리스트

### 6.1 목적

후보 종목 리스트는 오늘 장중에 실제로 볼 종목을 줄이는 단계입니다.

처음에는 하루 최대 5~15개 정도가 적당합니다. 30개 이상을 보면 집중력이 떨어지고, 시그널 알림도 많아집니다.

### 6.2 필수 필드

| 필드 | 설명 | 예시 |
|---|---|---|
| 종목코드 | 6자리 코드 | 000660 |
| 종목명 | 종목명 | SK하이닉스 |
| 시장 | KOSPI/KOSDAQ | KOSPI |
| 섹터/테마 | 내부 태그 | 반도체/HBM |
| 장전 등급 | A/B/C/제외 | A |
| 방향 Bias | 상승/하락/중립/관망 | 상승 |
| 관심 근거 | 뉴스, 섹터, 수급, 차트 등 | 미국 반도체 강세 |
| 리스크 태그 | 갭 과열, 저항, 유동성 부족 등 | 전고점 저항 |
| 관찰 가격 | 전일 고가, 전일 종가, 시초가 등 | 전일 고가 |
| 알림 활성 | 장중 시그널 알림 여부 | 활성 |
| 최종 행동 | 장후 입력 | 진입/보류/무시/미관찰 |

### 6.3 등급 체계

| 등급 | 의미 | 장중 운영 |
|---|---|---|
| A | 오늘 반드시 볼 종목 | 핵심 알림 활성, ChartView 상단 고정 |
| B | 조건부 관심 종목 | 강한 시그널이 나올 때만 확인 |
| C | 약한 관심 종목 | 원칙적으로 관망, 수동 확인만 |
| 제외 | 보지 않을 종목 | 알림 비활성, 리뷰 때만 참고 |

### 6.4 구현 방법

| 구현 요소 | 구체적 방안 |
|---|---|
| 1차 후보 생성 | 거래대금 상위, 전일 강세, 공시/뉴스 발생, 섹터 강도 기준으로 자동 후보 생성 |
| 수동 편집 | 사용자가 후보 추가/삭제, 등급 수정, Bias 수정 가능 |
| 알림 연결 | A/B 등급에만 VWAP/거래량/전고점 알림 적용 |
| 표시 방식 | 표 형태로 점수, 태그, 리스크, 알림 상태를 한 줄에 표시 |
| 저장 | 날짜별 watchlist로 저장하고 장후 결과와 연결 |

## 7. 템플릿 D: 종목별 판단 카드

### 7.1 목적

종목별 판단 카드는 “왜 이 종목을 보는가?”를 명확히 고정하는 문서입니다.

장중에는 가격 변동 때문에 판단이 흔들리기 쉽습니다. 종목 카드가 있으면 원래의 장전 가설과 무효화 조건을 계속 확인할 수 있습니다.

### 7.2 필수 필드

| 섹션 | 필드 | 설명 |
|---|---|---|
| 기본정보 | 종목명, 코드, 시장, 섹터 | 종목 식별 |
| 장전 판단 | 등급, Bias, 확신도 | 오늘 볼 우선순위 |
| 근거 | 시장, 섹터, 뉴스, 공시, 수급, 차트 | 관심 이유 |
| 리스크 | 과열, 저항, 거래대금 부족, 악재 | 주의 요인 |
| 가격 구조 | 전일 고가/저가/종가, 5일선, 20일선, 주요 매물대 | 관찰 가격 |
| 진입 시나리오 | VWAP 회복, 전고점 돌파, 눌림 지지 등 | 어떤 반응을 기다릴지 |
| 무효화 조건 | VWAP 재이탈, 시초가 이탈, 전일 종가 이탈 등 | 언제 포기할지 |
| 손절 기준 | 구조적 손절/ATR 기반 손절 | 리스크 제한 |
| 오늘 금지 조건 | 갭 과열 추격 금지 등 | 충동매매 방지 |
| 장후 결과 | 실제 고점/저점/종가, 거래 여부, 리뷰 | 사후 분석 |

### 7.3 종목 카드 예시

```text
종목: SK하이닉스
시장: KOSPI
섹터: 반도체/HBM
장전 등급: A
방향 Bias: 상승 우위
확신도: 4/5

핵심 근거:
- 전일 미국 반도체 지수 강세
- 국내 반도체 섹터 거래대금 증가
- 전일 고가 부근에서 거래량 증가

리스크:
- 단기 고점 부근 매물 부담
- 시초 갭이 과도하면 추격 위험

진입 시나리오:
- 시초 추격 금지
- 5~15분 관찰 후 VWAP 회복 및 거래량 증가 시 진입 검토
- 전일 고가 돌파 후 안착 시 추가 관심

무효화 조건:
- VWAP 아래 장시간 체류
- 시초가 이탈 후 반등 실패
- 섹터 대장주 동반 약세

손절 기준:
- VWAP 재이탈 또는 직전 저점 이탈
```

### 7.4 구현 방법

| 구현 요소 | 구체적 방안 |
|---|---|
| 카드 자동 초안 | 후보 리스트의 점수·태그·뉴스·공시 요약을 자동으로 불러와 초안 생성 |
| 사용자 입력 | Bias, 시나리오, 무효화 조건, 손절 기준은 사용자가 확정 |
| ChartView 연결 | 카드 우측 또는 하단에 전일 고저종, VWAP, 거래량 차트를 연결 |
| 장중 상태 업데이트 | 시그널 발생 시 카드에 타임라인 형태로 기록 |
| 장후 리뷰 연결 | 실제 결과와 판단 평가를 같은 카드에 이어붙임 |

## 9. 템플릿 F: 장후 리뷰 연결 필드

| 구분 | 질문 |
|---|---|

| 실행 품질 | 내가 진입/보류/무시를 잘 판단했나? |

### 9.2 장후 리뷰 필드

| 필드 | 설명 |
|---|---|
| 실제 장중 고점 | 장전 기준 이후 최고 상승률 |
| 실제 장중 저점 | 장전 기준 이후 최대 하락률 |
| 종가 결과 | 종가 기준 상승/하락 |

| 시그널 이후 결과 | 시그널 후 MFE/MAE, 종가 성과 |
| 사용자 행동 | 진입/보류/무시/놓침/관심해제 |
| 실행 평가 | 너무 빠름/늦음/적절/충동적 |
| 실패 원인 | 리서치/시그널/실행/리스크/시장 급변 |
| 개선 노트 | 다음날 반영할 규칙 |

### 9.3 구현 방법

| 구현 요소 | 구체적 방안 |
|---|---|

## 11. 후보 종목 점수화

### 11.1 점수화의 목적

초기 점수는 “매수 점수”가 아닙니다. **관찰 우선순위 점수**입니다.

즉, 점수가 높다고 자동 매수하는 것이 아니라, 장중에 먼저 볼 종목을 정하기 위한 기준입니다.

### 11.2 권장 점수 구성

| 항목 | 점수 | 설명 |
|---|---:|---|
| 시장 환경 | 0~10 | 지수/환율/금리/전일 분위기 |
| 섹터 강도 | 0~15 | 섹터 동반 상승, 거래대금 증가 |
| 종목 이벤트 | 0~20 | 뉴스, 공시, 실적, 정책, 테마 |
| 거래대금/유동성 | 0~15 | 단타 가능 거래대금과 호가 안정성 |
| 차트 위치 | 0~15 | 전고점, 지지선, 갭, VWAP 활용 가능성 |
| 수급 | 0~10 | 외국인/기관/프로그램 등 |
| 변동성 적합도 | 0~5 | 너무 죽어있지도, 과열도 아닌지 |
| 리스크 감점 | -20~0 | 과열, 악재, 투자주의, 거래정지 리스크 |
| 사용자 확신도 | 0~10 | 최종 사람 판단 |

### 11.3 등급 기준 예시

| 총점 | 등급 | 의미 |
|---:|---|---|
| 80점 이상 | A | 최우선 관찰 |
| 65~79점 | B | 조건부 관심 |
| 50~64점 | C | 약한 관심, 원칙적으로 관망 |
| 50점 미만 | 제외 | 보지 않음 |
| 리스크 플래그 | 제외 가능 | 점수와 무관하게 제외 |

### 11.4 점수화 구현 방법

| 구현 요소 | 구체적 방안 |
|---|---|
| 자동 점수 | 거래대금, 전일 등락, 섹터 강도, 공시 발생 여부 등 정량 항목 자동 계산 |
| 수동 점수 | 확신도, 뉴스 해석, 리스크 판단은 사용자가 조정 |
| 리스크 감점 | 투자주의, 과도한 갭, 저항 근접, 거래대금 부족 등 규칙 기반 감점 |
| 결과 비교 | 장후에 등급별 실제 성과와 Bias 적중률을 누적 |
| 기준 개선 | 2~4주마다 점수 항목과 가중치 조정 |

## 14. 장중 시그널 설계

### 14.1 시그널의 역할

시그널은 매수 명령이 아닙니다. **진입 검토 알림**입니다.

좋은 문구는 아래와 같습니다.

| 피해야 할 표현 | 권장 표현 |
|---|---|
| 매수 신호 발생 | 진입 검토 구간 |
| 강력 매수 | 상승 시나리오 유효 가능성 |
| 손절 신호 | 가설 훼손 가능성 |
| 매도 신호 | 리스크 재평가 필요 |

### 14.2 초기 추천 시그널 3개

#### 1) 상승 Bias + VWAP 회복형

```text
장전 A/B 등급
+ 상승 Bias
+ 가격이 VWAP 회복
+ 거래량 증가
+ 손절 기준 명확
= 진입 검토 알림
```

#### 2) 상승 Bias + 전일 고가 돌파형

```text
장전 A/B 등급
+ 시장/섹터 우호
+ 전일 고가 또는 장중 고점 돌파
+ 거래량 증가
+ VWAP 위 유지
= 진입 검토 알림
```

#### 3) 상승 Bias 실패형

```text
장전 A/B 등급
+ 상승 Bias였음
+ VWAP 아래 체류
+ 반등 시 VWAP 저항
+ 거래량 약화
= 관심 해제 또는 진입 금지
```

### 14.3 ADX와 ATR 활용 위치

| 지표 | 초기 활용 방식 |
|---|---|
| VWAP | 장중 기준선, 회복/이탈 알림 |
| 거래량 | 참여도 확인, 신호 신뢰도 보강 |
| 전일 고가/저가/종가 | 가격 구조와 돌파/이탈 기준 |
| ATR | 손절폭과 변동성 판단 |
| ADX | 진입 트리거가 아니라 추세 강도 필터 |

## 20. 핵심 원칙

### 원칙 1. 시그널은 종목 선정 도구가 아니라 진입 보조 도구다

VWAP 회복이 떴다고 종목을 찾는 것이 아니라, 장전에 고른 A/B 종목에서 VWAP 회복이 나왔는지를 봐야 합니다.

### 원칙 2. 점수는 매수 점수가 아니라 관찰 우선순위다

높은 점수는 “먼저 보라”는 뜻이지 “사라”는 뜻이 아닙니다.

### 원칙 3. 리서치와 실행을 분리해서 저장해야 한다

수익/손실만 보면 개선이 어렵습니다. 종목 선정, 방향 판단, 시그널, 실행을 분리해야 합니다.

### 원칙 4. 알림은 적어야 한다

처음부터 많은 알림을 받으면 결국 무시하게 됩니다. A/B 종목에 대해서만 핵심 알림을 받는 것이 좋습니다.

### 원칙 5. 장후 리뷰가 없으면 시스템이 아니다

장전 판단과 장중 행동을 비교해야만 내 판단력이 좋아집니다.

## 21. 최종 권장안

국내장 Phase 1은 아래 6개만 제대로 구현하면 충분합니다.

1. **장전 시장 브리핑**  
   오늘 시장이 공격/방어/중립인지 판단합니다.

2. **섹터·테마 맵**  
   오늘 돈이 몰릴 가능성이 있는 영역과 피할 영역을 정합니다.

3. **후보 종목 리스트**  
   하루에 볼 종목을 A/B/C/제외로 줄입니다.

4. **종목별 판단 카드**  
   근거, 리스크, 진입 시나리오, 무효화 조건을 기록합니다.

5. **장중 시그널 알림**  
   A/B 종목에 대해서만 VWAP·거래량·전일 고가 알림을 받습니다.

6. **장후 리뷰**  
   판단, 시그널, 실행, 결과를 분리해서 개선합니다.

이 구조가 자리 잡으면 이후 Phase 2에서 ChartView 고도화, AI 요약, 플레이북별 통계, 제한적 전략화로 확장할 수 있습니다.

## 부록 D. Phase 1 완료 기준

Phase 1은 아래 조건을 만족하면 완료로 볼 수 있습니다.

- 매일 장전 15~30분 안에 시장 브리핑과 후보 리스트를 확정할 수 있다.
- 하루 후보 종목이 5~15개 수준으로 압축된다.
- 각 후보 종목에 대해 근거, 리스크, 진입 시나리오, 무효화 조건이 기록된다.
- A/B 종목에 대해서만 장중 핵심 시그널 알림이 발생한다.
- 사용자가 진입/보류/무시/놓침/관심해제를 기록할 수 있다.
- 장후에 등급별, Bias별, 시그널별 결과를 볼 수 있다.
- 2~4주 후 내가 어떤 조건에서 잘 맞히고, 어떤 조건에서 자주 틀리는지 확인할 수 있다.
